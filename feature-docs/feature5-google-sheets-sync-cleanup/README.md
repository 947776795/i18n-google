## 三方数据合并逻辑

### 数据源

```
┌─────────────────────────────────────────────────────────────────────────┐
│  1. 远端数据（Google Sheets）                                             │
│     格式: { "[app/page.tsx][Welcome]": { en: "Welcome", ko: "환영" } }   │
├─────────────────────────────────────────────────────────────────────────┤
│  2. 本地记录（i18n-complete-record.json）                                 │
│     格式: { "app": { "en.json": { "Welcome": "Welcome" } } }             │
├─────────────────────────────────────────────────────────────────────────┤
│  3. 新扫描 keys                                                          │
│     格式: Set<"Welcome", "Settings">                                     │
└─────────────────────────────────────────────────────────────────────────┘
```

### 合并规则

```
┌─────────────────────────────────────────────────────────────────────────┐
│  老 keys（已存在于本地或远端）                                            │
│  ┌─────────────┐                                                        │
│  │ 远端有翻译？ │──→ 是 ──→ 采用远端翻译                                  │
│  └─────────────┘                                                        │
│       │ 否                                                              │
│       ↓                                                                 │
│  ┌─────────────┐                                                        │
│  │ 本地有翻译？ │──→ 是 ──→ 采用本地翻译                                  │
│  └─────────────┘                                                        │
│                                                                         │
├─────────────────────────────────────────────────────────────────────────┤
│  新 keys（扫描发现）                                                     │
│  → 直接添加，值 = 原文（待翻译）                                           │
└─────────────────────────────────────────────────────────────────────────┘
```

### 举例

| key | 远端 | 本地 | 新扫描 | 结果 |
|-----|------|------|--------|------|
| Welcome | "Welcome"/"환영" | "Welcome"/"환영" | ✅ | 采用远端 |
| Title | "My App"/"내 앱" | "Title"/"" | | 采用远端 |
| Login | | "Login"/"로그인" | | 采用本地 |
| Settings | | | ✅ | 原文 |

## 无用 Keys 检测逻辑

### 核心公式

```
现有翻译记录中的 keys  -  当前代码中实际使用的 keys  =  无用的 keys
```

### 检测步骤

```
1. 收集当前代码中的 I18n.t() 引用
   └── Set<{ folderName: string, key: string }>

2. 读取现有翻译记录中的所有 keys
   └── Set<{ folderName: string, key: string }>

3. 比对差异
   └── 记录中有但引用中没有的 = 无用 keys

4. 匹配规则（处理路径不一致）
   ├── 精确匹配：模块路径相同
   ├── 后缀匹配：代码路径.endsWith(模块路径)
   └── 同名文件：文件名相同

5. 提示用户
   └── "发现 N 个无用 keys，是否删除? (y/N)"
```
